# جوجو Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** PWA على `/jojo/` لجوجو (عادات + نسبة التزام + قهوة بقراءة الكيس + رسائل صالح) وصفحة مؤقتة لصالح `/jojo/saleh/`.

**Architecture:** منطق نقي في `jojo/core.js` (UMD: يشتغل بالمتصفح وبـ `node --test`)، وواجهة ملف واحد `jojo/index.html` تكلّم Supabase (مشروع khazna) عبر REST وAuth مثل `lab/index.html`. الأسرار (Claude، Notion، VAPID) في edge functions فقط.

**Tech Stack:** HTML/CSS/JS بدون bundler · Supabase (Auth, Postgres+RLS, Edge Functions Deno, pg_cron) · `npm:adhan` · `npm:web-push@3.6.7` · Claude API (`claude-haiku-5-5`، صور) · Notion API.

**Spec:** `docs/superpowers/specs/2026-11-24-jojo-design.md`

## Global Constraints
- مشروع Supabase: **khazna** (`lpsifrdiangpfcwhjeim`). كل الجداول بادئتها `jojo_` وRLS مفعّل على كلها.
- المنطقة الزمنية الافتراضية `Asia/Riyadh`؛ "اليوم" = التاريخ المحلي لجوجو، مو UTC.
- الألوان (وضع داكن): أرضية `#141012`، بطاقات `#1F191C`، نص وايت شوكلت `#F6EEE3`، وردي `#F4A7C0`. المرجع البصري: `jojo/proto/today.html` (معتمد). RTL كامل وعربي.
- ممنوع أي حقل أو نص عن الوزن أو المقاسات أو السعرات.
- صالح ما يقرأ أبدًا: `jojo_notes`، تفاصيل `jojo_checks`، `jojo_tasks`.
- أي وصفة غير ريز تظهر عليها شارة **"غير معتمدة"**. وصفات ريز تُظهر اسم الصفحة المصدر "📋 الوصفات المعتمدة".
- مفاتيح Claude وNotion وVAPID الخاص لا تظهر في أي ملف داخل `jojo/` (التحقق: `grep -R "sk-ant\|secret_\|ntn_" jojo/` يرجع فاضي).
- الواجهة تُبنى بمهارة impeccable-design، بإحساس Pinterest ناعم (بطاقات دائرية، فيونكات، قطاوة).

## Review Focus
1. **حدود اليوم:** تأشير الساعة 11:58م وفتح التطبيق 12:01ص → كل تأشير ينحسب على تاريخه المحلي، واليوم الجديد يبدأ فاضي. (اختبار في Task 1)
2. **يوم راحة النادي:** النسبة ما تنقص لأن النادي ما انعمل يوم راحة. (Task 1)
3. **قائمة فيتامينات فاضية:** ما تصير بند مطلوب ولا تقسم على صفر. (Task 1)
4. **بدون إنترنت:** التأشير ينحفظ محليًا ويترفع لما يرجع الاتصال، بدون تكرار. (Task 6)
5. **صورة كيس مو واضحة أو مو كيس قهوة:** رسالة لطيفة "ما قدرت أقرأ الكيس" وتقدر تكتب الاسم يدويًا، بدون كراش. (Task 5 + 7)

**Files:** Create `jojo/core.js`, `jojo/test/score.test.js`

**Interfaces:**

- مفاتيح البنود: `prayer:fajr|dhuhr|asr|maghrib|isha`, `sleep`, `wake`, `meal:breakfast|lunch|dinner`, `vitamins`, `water`, `gym`, `task:<id>`.
